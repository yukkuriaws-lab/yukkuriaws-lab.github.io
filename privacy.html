プライバシーポリシー

「ゆっくりAWS 投稿」（以下「本アプリ」）は、運営者が自分の YouTube チャンネルを操作するためだけに使います。

使うデータ

本アプリは Google の OAuth で運営者自身のアカウントの許可を受け、YouTube Data API で運営者のチャンネルの動画の情報（タイトル、説明、タグ、サムネイル、字幕、公開設定）を読み書きします。運営者以外の利用者のデータは扱いません。

保存と共有

認証のトークンは運営者の作業用の端末に、運営者だけが読める権限で保存します。データを第三者に販売・共有・広告に利用することはありません。

本アプリによる Google API から受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消し

許可は Google アカウントのサードパーティ接続 からいつでも取り消せます。
